# 项目说明

## 1. 项目定位

“空天智感——机翼应变智能监测系统”是一套面向航空结构健康监测的科研与竞赛型软件平台。系统围绕机翼48通道应变数据，完成损伤识别、载荷反演、损伤参数预测、迁移学习和三维应变场重构。

## 2. 数据与模型流程

系统以48通道应变为统一输入。首先由BP分类模型判断当前结构是否存在损伤；若判定为无损伤，则调用3个CNN模型分别预测载荷位置x、z与载荷大小；若判定为有损伤，则调用另外3个CNN模型分别预测损伤位置x、z与损伤尺寸。随后，LC-Kriging模块根据48个离散测点重构连续应变场，并结合当前三维机翼模型和传感器坐标进行可视化。

## 3. 预训练与迁移学习

模型训练采用两阶段流程。第一阶段使用仿真数据完成BP/CNN预训练，形成迁移前模型；第二阶段以预训练模型为基础，引入实际试验数据，通过AE共享特征、教师知识蒸馏和学生模型微调实现仿真域向实测域迁移。

## 4. 软件模块

- 在线监测与三维应变云图
- 预训练模型训练
- 迁移学习与后台模型更新
- 七模型组合导入
- 三维机翼模型独立管理
- 48点传感器手动布置
- LC-Kriging应变场重构

## 5. 独立模块设计

机翼三维模型、传感器坐标和识别模型相互独立。更新模型不会覆盖机翼几何和传感器布置；更换机翼不会自动改变模型；调整48点坐标也不会影响后台模型。这样的结构便于试验过程中频繁替换模型、几何和测点方案。

## 6. Windows版本

GitHub Actions用于构建Windows x64 GUI版本。构建成功后会生成 `AerospaceWingMonitor-Windows-x64` artifact，解压后可直接运行 `空天智感_机翼应变智能监测系统.exe`。
