# 空天智感——机翼应变智能监测系统

> 面向航空结构健康监测（SHM）的机翼应变智能分析平台

**团队：空天智感团队**  
**平台：Windows x64 GUI**  
**当前版本：三维云图一致性修正版**

## 项目简介

本项目面向机翼及薄壁航空结构的应变监测、载荷反演与损伤识别需求，构建集 **48 通道应变数据输入、智能模型推理、迁移学习、LC-Kriging 应变场重构、三维机翼可视化和模型管理** 于一体的结构健康监测软件平台。

系统以 48 个应变传感器数据为核心输入，通过损伤分类模型判断结构状态，并调用对应的回归模型完成载荷参数或损伤参数预测；随后利用 LC-Kriging 方法重构连续应变场，并将同一应变场映射至三维机翼模型，实现二维俯视云图与三维表面云图的一致显示。

## 核心功能

- 48 通道应变数据管理与传感器坐标配置
- BP 损伤分类
- 无损状态：载荷展向位置、弦向位置和载荷大小预测
- 损伤状态：损伤展向位置、弦向位置和损伤尺寸预测
- 七模型独立导入与管理
- 输入/输出归一化器独立配置
- 预训练 → 迁移学习两阶段模型流程
- AE 共享表征与知识蒸馏迁移
- LC-Kriging 连续应变场重构
- STL / OBJ 等三维机翼模型管理
- 48 个传感器手动布置
- 二维应变云图与三维机翼云图联动显示
- Windows x64 无控制台 GUI 可执行程序

## 七模型推理结构

```text
48 通道应变
      │
      ▼
BP 损伤分类
  ┌───┴───┐
  │       │
无损     损伤
  │       │
  ├─载荷 x  ├─损伤 x
  ├─载荷 z  ├─损伤 z
  └─载荷大小 └─损伤尺寸
      │
      ▼
LC-Kriging 应变场重构
      │
      ▼
二维云图 + 三维机翼表面映射
```

## 三维云图一致性修正

当前版本已修正更换三维机翼模型后出现的大块三角形着色问题。二维俯视图和三维机翼表面现在使用 **同一个 LC-Kriging 连续应变场**：三维模型仅提供几何外形与厚度信息，不再由 STL/OBJ 网格粗细决定应变场显示分辨率，从而保证二维和三维结果具有一致的物理坐标与颜色分布。

## Windows 构建

仓库通过 GitHub Actions 在 Windows x64 环境中自动构建 GUI 可执行程序，并进行启动冒烟测试。最终用户可直接运行：

```text
空天智感_机翼应变智能监测系统.exe
```

无需单独安装 Python 环境。

## 应用方向

本系统可用于机翼结构地面加载试验、复合材料/薄壁结构健康监测研究、仿真到实测迁移验证，以及载荷与损伤状态的智能识别和可视化分析。

## 团队介绍

**空天智感团队**面向航空结构智能感知与安全监测需求，聚焦机翼应变感知、损伤识别、载荷反演与三维应变场重构等关键问题。团队融合多通道应变传感、BP/CNN 深度学习、迁移学习与 LC-Kriging 重构方法，致力于推动人工智能技术在航空结构监测与装备安全保障中的工程化应用。
