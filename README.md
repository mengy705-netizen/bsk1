# 空天智感——机翼应变智能监测系统

面向航空结构健康监测（SHM）的机翼应变智能分析软件，融合48通道应变感知、BP/CNN预训练、迁移学习、七模型联合推理、LC-Kriging应变场重构和三维机翼可视化。

## 项目简介

本项目由**空天智感团队**开发，以48通道应变数据为核心输入，构建“预训练—迁移学习—在线推理—应变场重构—三维可视化”的完整流程，实现无损/有损状态识别、载荷参数预测、损伤位置与尺寸预测，并将结果映射到三维机翼模型中进行显示。

系统将模型训练、迁移学习、外部模型导入、机翼三维模型管理、48点传感器布置和在线监测相互独立，便于后续更换模型、调整传感器位置或替换机翼几何模型。

## 核心功能

- 48通道应变数据输入与在线监测
- BP损伤分类：判断无损伤/有损伤
- 无损分支：CNN预测载荷位置x、z及载荷大小
- 损伤分支：CNN预测损伤位置x、z及损伤尺寸
- 两阶段训练：先预训练，再进行迁移学习
- AE共享特征、知识蒸馏与目标域微调
- 七模型组合导入，每个模型可单独配置可选归一化文件
- LC-Kriging应变场重构
- 三维机翼模型独立管理
- 48个传感器位置逐点手动布置
- 后台模型独立更新
- 三维应变云图及载荷/损伤位置可视化

## 模型流程

```text
48通道应变
    ↓
BP损伤分类
 ┌──┴──┐
无损   有损
 ↓      ↓
3个CNN  3个CNN
载荷    损伤
x/z/大小 x/z/尺寸
 └──┬──┘
    ↓
LC-Kriging重构
    ↓
三维机翼在线显示
```

## 两阶段训练

第一阶段使用仿真未损伤与仿真损伤数据完成BP/CNN预训练，获得迁移前模型；第二阶段在预训练模型基础上，引入实际数据，通过AE特征迁移、教师知识蒸馏和学生模型微调完成仿真域到实测域的迁移。

```text
仿真数据 → BP/CNN预训练 → 预训练模型
                         ↓
              AE特征迁移 + 知识蒸馏
                         ↓
                    实际数据微调
                         ↓
                    迁移后模型
```

## 七模型组合

| 模型 | 作用 |
|---|---|
| BP分类模型 | 判断无损伤/有损伤 |
| 无损 load_x | 载荷位置x |
| 无损 load_z | 载荷位置z |
| 无损 load_size | 载荷大小 |
| 损伤 damage_x | 损伤位置x |
| 损伤 damage_z | 损伤位置z |
| 损伤 damage_size | 损伤尺寸 |

每个模型可独立选择模型文件和输入归一化文件，回归模型还可独立选择输出归一化文件；模型内部已经包含归一化时，相应文件可以留空。

## 三维机翼与传感器

机翼三维模型和48点传感器布置均为独立功能。传感器编号1—48必须与训练数据中的48个输入通道顺序一致。更换机翼模型不会自动覆盖原有传感器坐标，可在“传感器布置”页面重新逐点调整。

## 应用方向

**空天智感团队**
